# SketchyBar 个性化配置设计规格

**日期**：2026-03-23
**项目**：sketchybar-dotfiles-redesign
**设计风格**：极简主义 × Rose Pine × 悬浮卡片式布局

---

## 1. 视觉风格

### 主题
- **配色方案**：Rose Pine 标准版
- **设计哲学**：极简主义 — 只保留必要信息，减少视觉噪音
- **布局哲学**：悬浮卡片式 — 每个模块为独立卡片，状态栏底座完全透明

### 配色（Rose Pine 标准版）

| 用途 | 色值 | 说明 |
|------|------|------|
| 卡片背景 | `#232136` | 各模块圆角矩形背景 |
| 文字主色 | `#e0def4` | 高亮文字、图标 |
| 文字次色 | `#908c99` | 一般标签文字 |
| 文字淡化 | `#6e6a86` | 未选中状态 |
| 强调色 | `#c4a7e7` | 选中高亮（紫罗兰） |
| 暖金色 | `#f6c177` | 当前播放指示 |
| 玫瑰粉 | `#eb6f92` | 分隔线、装饰 |

### 字体
- **字体族**：JetBrains Mono Nerd Font
- **图标字号**：15px
- **标签字号**：12px
- **备选**：Hack Nerd Font（当前已在用）

---

## 2. 整体布局

### 状态栏底座
- **高度**：25px
- **背景**：完全透明 `0x00000000`（无 blur，无颜色）
- **定位**：top

### 模块排列（从左到右）

```
┌──────────────────────────────────────────────────────────────┐
│ [ 1 ][ 2 ][ 3 ]...  │  [ 🎵 曲目 – 艺术家 ]  │  [ Wx ][ Ob ][ Vi ][ Gt ]  [ 📅 ]  [ 🕐 ]  │
│    工作区（左侧）      中间：当前播放            右侧：App图标  日历  时钟        │
└──────────────────────────────────────────────────────────────┘
```

- **左侧（left）**：工作区指示器组
- **中间（center）**：当前播放
- **右侧（right）**：常用 App 图标组 → 日历 → 时钟

---

## 3. 各模块详细设计

### 3.1 工作区（左侧）

- **数量**：10 个 space（数字 1-10）
- **卡片尺寸**：高度 22px，圆角 4px，padding 4px 8px
- **间距**：各 space 之间 4px
- **背景**：透明（未选中）/ `#66c4a7e7`（选中，40% 不透明紫罗兰）
- **文字颜色**：淡化色 `#6e6a86`（未选中）/ 主色 `#e0def4`（选中）
- **交互**：点击切换工作区 `yabai -m space --focus $sid`

### 3.2 当前播放（中间）

- **卡片尺寸**：动态宽度（按内容撑开），高度 22px，圆角 4px，padding 4px 8px
- **背景色**：`#232136`
- **图标**：🍾 或 🎵，颜色 `#f6c177`（暖金色）
- **文字格式**：`曲目名 – 艺术家`
- **文字颜色**：`#e0def4`
- **截断规则**：超过 30 字符的曲目名截断为 `曲目名… – 艺术家`
- **数据来源**：通过 `sketchybar-music` 或 `now-playing-cli` 脚本获取当前播放信息
- **空状态**：无播放时显示 `—`

### 3.3 常用 App（右侧）

- **App 列表**：微信、Obsidian、Vivaldi、Ghostty
- **排列顺序**：从左到右依次排列
- **每个 App 卡片**：尺寸 22×22px，圆角 4px，padding 4px
- **背景色**：`#232136`
- **显示内容**：App 图标（SF Symbols 或 Nerd Font）
- **图标颜色**：`#e0def4`
- **悬停/点击**：图标颜色变为 `#c4a7e7`
- **点击脚本**：`open -a "WeChat"` 等对应 App Bundle ID

| App | Bundle ID / 启动命令 |
|-----|---------------------|
| 微信 | `open -a "WeChat"` |
| Obsidian | `open -a "Obsidian"` |
| Vivaldi | `open -a "Vivaldi"` |
| Ghostty | `open -a "Ghostty"` |

### 3.4 日历（右侧）

- **卡片尺寸**：固定宽度（按内容），高度 22px，圆角 4px，padding 4px 8px
- **背景色**：`#232136`
- **显示格式**：`23 Mar`（日 + 月，首字母大写）
- **文字颜色**：`#908c99`
- **点击行为**：点击后执行 `open -a Calendar` 打开系统日历
- **数据来源**：读取系统日期格式化

### 3.5 时钟（右侧）

- **卡片尺寸**：固定宽度（按内容），高度 22px，圆角 4px，padding 4px 8px
- **背景色**：`#232136`
- **显示格式**：`14:30`（24 小时制）
- **文字颜色**：`#e0def4`（比日历略亮，视觉层级最高）
- **刷新频率**：每 30 秒

## 4. 间距系统

| 间距类型 | 数值 |
|----------|------|
| 模块卡片间距 | 6px |
| 卡片内部 padding | 4px 8px |
| App 图标间距 | 4px |
| 状态栏左右边距 | 10px（系统默认值） |

---

## 5. 脚本与环境

### 脚本目录结构
```
plugins/
├── space.sh          # 工作区切换
├── front_app.sh      # 当前聚焦应用（保留，备用）
├── clock.sh          # 时钟刷新
├── calendar.sh       # 日历日期
├── volume.sh         # 音量（暂时移除，可扩展）
├── battery.sh        # 电池（暂时移除，可扩展）
├── music.sh          # 当前播放信息（新建）
└── app_launcher.sh   # 常用 App 启动（新建）
```

### 依赖
- **sketchybar**（最新版）
- **yabai**（工作区切换）
- **now-playing-cli** 或 **sketchybar-music**（当前播放信息获取）
